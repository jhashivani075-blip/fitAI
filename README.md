# FitAI Website Demo

A responsive, single-page fitness dashboard prototype built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
1. Create a GitHub repository and upload `index.html`.
2. Import that repository into Vercel, or drag the folder into Netlify Drop.
3. No build command is required; the output is the repository root.

## Important limitations
This is a frontend prototype with sample dashboard values and preset demo responses. It does not yet include real authentication, a database, a live AI API, image-based form analysis, or persistent user progress. Add a secure backend before collecting user data. Never put API keys in frontend JavaScript.
